# Secure Password Generator

## About
A beginner-friendly Python project that generates random sample passwords using Python's secure random module.

## Features
- Accepts password length from the user.
- Uses uppercase and lowercase letters.
- Includes numbers and special characters.
- Uses Python's secrets module.
- Requires a minimum length of 12 characters.

## Technologies Used
- Python
- secrets module
- string module

## How to Run
1. Install Python.
2. Open a terminal in the project folder.
3. Run:
python password_generator.py
4. Enter a password length of at least 12 characters.

- Random generation
