# Encryption and Cryptography Fundamentals

## Objective
To understand how cryptography protects information and communication.

## What is Cryptography?
Cryptography is the technique of protecting information by converting it into a form that unauthorized people cannot easily understand.

## What is Encryption?
Encryption converts readable information (plaintext) into an unreadable form (ciphertext) using an algorithm and a key.

## What is Decryption?
Decryption converts ciphertext back into readable plaintext using the appropriate key.

## Types of Encryption

### 1. Symmetric Encryption
Uses the same secret key for encryption and decryption.

Example: AES.

### 2. Asymmetric Encryption
Uses a pair of keys:
- Public key
- Private key

Examples: RSA and ECC.

## Important Cryptography Concepts
- Plaintext – Original readable information.
- Ciphertext – Encrypted information.
- Key – Value used by a cryptographic algorithm.
- Hashing – Produces a fixed-length digest from input data.
- Digital Signature – Helps verify message authenticity and integrity.

## Real-Life Applications
- Secure online banking.
- HTTPS communication.
- Secure messaging.
- Digital signatures.
- Password storage using suitable password-hashing methods.

## Learning Outcomes
- Understanding encryption and decryption.
- Identifying symmetric and asymmetric encryption.
- Learning basic cryptography terminology.
- Understanding how cryptography supports information security.

Learned the basic concepts and applications of cryptography.
