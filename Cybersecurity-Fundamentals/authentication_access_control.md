# Authentication and Access Control

## Objective
To understand how systems verify users and control access to resources.

## What is Authentication?
Authentication is the process of verifying the identity of a user before allowing access to a system.

## Types of Authentication

### 1. Password Authentication
Uses a username and password to verify a user.

### 2. Biometric Authentication
Uses unique biological characteristics, such as fingerprints or facial recognition.

### 3. Multi-Factor Authentication (MFA)
Uses two or more different types of verification to improve account security.

### 4. Token-Based Authentication
Uses a digital token to verify a user's identity or session.

## What is Authorization?
Authorization determines what an authenticated user is allowed to access or do.

## Authentication vs Authorization

| Authentication | Authorization |
|---|---|
| Verifies identity | Determines permissions |
| Happens first | Follows authentication |
| Example: Login | Example: Accessing an admin page |

## What is Access Control?
Access control is a security mechanism that restricts access to resources based on permissions and policies.

## Common Access Control Models
- DAC – Discretionary Access Control
- MAC – Mandatory Access Control
- RBAC – Role-Based Access Control
- ABAC – Attribute-Based Access Control

## Best Security Practices
- Use strong, unique passwords.
- Enable MFA.
- Give users only necessary permissions.
- Review account permissions regularly.
- Remove access when it is no longer needed.

## Learning Outcomes
- Understanding authentication and authorization.
- Learning access control models.
- Understanding MFA and user permissions.

## Result
Learned how authentication and access control help protect systems and information.
