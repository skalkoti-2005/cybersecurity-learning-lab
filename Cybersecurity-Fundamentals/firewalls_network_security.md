# Firewalls and Network Security

## Objective
To understand firewalls and their role in protecting computer networks.

## What is a Firewall?
A firewall is a network security system that monitors and controls incoming and outgoing network traffic based on predefined security rules.

## Types of Firewalls

### 1. Packet Filtering Firewall
Filters network packets based on information such as IP addresses, ports, and protocols.

### 2. Stateful Firewall
Tracks active network connections and makes decisions based on connection state.

### 3. Proxy Firewall
Acts as an intermediary between users and external services.

### 4. Next-Generation Firewall (NGFW)
Combines traditional firewall functions with additional security features such as application awareness and intrusion prevention.

## What is Network Security?
Network security involves protecting network devices, connections, and data from unauthorized access and cyber threats.

## Important Network Security Practices
- Use strong authentication.
- Enable firewalls.
- Keep network devices updated.
- Use secure protocols.
- Monitor network activity.
- Use network segmentation.
- Secure wireless networks.

## Real-Life Example
A college network firewall can restrict access to certain websites and block unauthorized network connections.

## Learning Outcomes
- Understanding firewalls.
- Identifying different firewall types.
- Learning basic network security practices.
- Understanding traffic filtering.

## Result
Learned the purpose of firewalls and their role in network security.
