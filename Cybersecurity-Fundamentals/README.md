# Cybersecurity Fundamentals

## About
This section contains my beginner-level cybersecurity notes and practical concepts.

## What is Cybersecurity?
Cybersecurity is the practice of protecting computers, networks, applications, and data from unauthorized access, damage, and digital threats.

## Main Areas of Cybersecurity

### 1. Network Security
Protects computer networks from unauthorized access and threats.

### 2. Application Security
Protects software and web applications from security weaknesses.

### 3. Information Security
Protects information from unauthorized access, modification, or loss.

### 4. Endpoint Security
Protects devices such as computers, laptops, and mobile phones.

### 5. Digital Forensics
Involves collecting and examining digital evidence to understand security incidents.

## Common Cybersecurity Threats
- Phishing

- Ransomware

- Denial of Service (DoS)

## Important Security Concepts
- Confidentiality
- Integrity
