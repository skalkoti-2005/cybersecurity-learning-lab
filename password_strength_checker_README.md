# Password Strength Checker

## About
A beginner-friendly Python project that checks password strength using basic rules.

## Features
- Checks password length.
- Checks uppercase and lowercase letters.
- Checks numbers and special characters.
- Displays a password strength result.

## Technology Used
- Python
- String handling
- Conditional statements

## Learning Outcome
Learned basic Python programming and password security concepts.

## Disclaimer
This is an educational project and does not provide a complete password security assessment.
