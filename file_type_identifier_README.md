# File Type Identifier

## About
A beginner-friendly Python project that identifies common file types using their filename extensions.

## Features
- Accepts a filename as input.
- Extracts the file extension.
- Identifies common document, image, audio, and video formats.
- Displays Unknown File Type for unsupported extensions.

## Technologies Used
- Python
- Dictionaries
- String operations
- Conditional statements

## How to Run
1. Install Python.
2. Open a terminal in the project folder.
3. Run:
python file_type_identifier.py
4. Enter a sample filename, such as `notes.pdf` or `photo.jpg`.

## Learning Outcomes
- Working with strings
- Using dictionaries
- Understanding file extensions
- Writing conditional statements
