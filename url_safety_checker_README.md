# URL Safety Checker

## About
A beginner-friendly Python project that checks a URL for a few predefined suspicious patterns.

## Features
- Accepts a sample URL.
- Checks for HTTP instead of HTTPS.
- Checks for the @ symbol.
- Checks for multiple hyphens.
- Searches for selected suspicious words.
- Displays a simple pattern score.

## Technologies Used
- Python
- Strings
- Lists
- Loops
- Conditional statements

## How to Run
1. Install Python.
2. Open a terminal in the project folder.
3. Run:
python url_safety_checker.py
4. Enter a made-up sample URL.

## Learning Outcomes
- String checking
- Using lists and loops
- Conditional logic
- Introduction to suspicious URL patterns
