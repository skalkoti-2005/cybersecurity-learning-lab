# Linux User and Group Management

## Objective
To understand how Linux manages users and groups.

## About
Linux supports multiple users. User and group management helps control access to files and system resources.

## Important Commands

| Command | Purpose |
|---|---|
| `whoami` | Displays the current username |
| `id` | Displays user and group IDs |
| `who` | Shows logged-in users |
| `groups` | Displays group memberships |
| `passwd` | Changes the current user's password |
| `getent passwd` | Lists user account records |
| `getent group` | Lists group records |

## Practice Commands
whoami
id
groups

getent group

## Important Concepts
- User – An account that can access the Linux system.
- Group – A collection of users.
- UID – User ID.
- GID – Group ID.
- Root – The system administrator account.

## Learning Outcomes
- Understanding Linux users and groups.
- Identifying UID and GID.
- Viewing account information.
- Understanding access management.

## Result
Learned basic Linux user and group management concepts.
