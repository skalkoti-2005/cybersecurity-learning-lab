# Linux System Log Analysis

## Objective
To understand how Linux system logs record system events and how to view them.

## What are System Logs?
System logs are records of activities and events generated by the operating system and applications. They help with troubleshooting and security monitoring.

## Important Log Locations

| Log | Purpose |
|---|---|
| `/var/log/syslog` | General system messages on some Linux distributions |
| `/var/log/auth.log` | Authentication-related events on Debian-based systems |
| `/var/log/kern.log` | Kernel messages on some distributions |
| `/var/log/` | Directory containing many system logs |

## Important Commands

| Command | Purpose |
|---|---|
| `journalctl` | Views system journal logs |
| `journalctl -n 20` | Displays the latest 20 journal entries |
| `journalctl -b` | Displays logs from the current boot |
| `tail -n 20 sample.log` | Displays the last 20 lines of a sample log |
| `grep "ERROR" sample.log` | Finds lines containing ERROR |

## Practice
Use a sample log file created in your own practice folder:
echo "INFO: System started" > sample.log
echo "ERROR: Sample application error" >> sample.log
echo "WARNING: Sample warning" >> sample.log
cat sample.log
grep "ERROR" sample.log
tail -n 2 sample.log
