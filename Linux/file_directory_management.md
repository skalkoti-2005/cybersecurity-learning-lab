# Linux File and Directory Management

## Objective
To learn how to create, view, rename, copy, and manage files and directories using Linux commands.

## Commands Practised

| Command | Purpose |
|---|---|
| `pwd` | Shows the current directory |
| `ls` | Lists files and folders |
| `mkdir lab` | Creates a folder named lab |
| `cd lab` | Enters the lab folder |
| `touch sample.txt` | Creates an empty file |
| `echo "Hello Linux" > sample.txt` | Writes sample text into a file |
| `cat sample.txt` | Displays file contents |
| `cp sample.txt copy.txt` | Copies a file |
| `mv copy.txt renamed.txt` | Renames a file |
| `ls -l` | Shows detailed file information |

## Procedure
1. Open the Linux terminal.
2. Check the current directory using `pwd`.
3. Create a practice folder using `mkdir lab`.
4. Enter it using `cd lab`.
5. Create a sample file using `touch sample.txt`.
6. Add sample text and display it.
7. Copy and rename the sample file.
8. Use `ls -l` to verify the files.

## Learning Outcomes
- Creating files and directories.
- Navigating the Linux file system.
- Copying and renaming files.
- Viewing file contents.

## Result
Learned basic Linux file and directory management commands.
