# Digital Forensics

This folder contains my learning notes about digital forensics, evidence analysis and basic incident investigation concepts.

## Topics Covered

- Introduction to Digital Forensics
- Digital Evidence
- Email Header Analysis
- IP Address Investigation
- Log Analysis
- File Metadata
- File Integrity and Hashing
- Incident Response
- Evidence Documentation

## Tools and Technologies

- Kali Linux
- Python
- Linux Terminal
- Wireshark

## Learning Objectives

- Understand digital forensic investigation concepts.
- Learn how digital evidence is identified and documented.
- Explore email and network analysis.
- Understand the importance of evidence integrity.
- Develop basic forensic investigation skills.

## Purpose

To develop practical knowledge of digital forensics and understand its role in cybersecurity investigations.
