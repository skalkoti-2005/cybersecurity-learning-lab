# File Integrity Checker

## About
This Python project calculates the SHA-256 hash of a file. Hashes can help identify whether a file has changed.

## Features
- Reads a file.
- Calculates its SHA-256 hash.
- Displays the hash value.
- Handles files that cannot be found.

## Technologies Used
- Python
- hashlib library

## How to Run
1. Install Python.
2. Keep a sample text file in the same folder.
3. Open the terminal in that folder.
4. Run:python file_integrity_checker.py
5. Enter the sample filename when prompted.

## Learning Outcomes
- File handling in Python
- SHA-256 hashing
- Exception handling
- Basic file integrity concepts
