# Log File Analyzer

## About
A beginner-friendly Python project that reads a sample log file and counts the total entries, errors, and warnings.

## Features
- Reads text-based log files.
- Counts total log entries.
- Identifies entries containing ERROR.
- Identifies entries containing WARNING.
- Handles missing files.

## Technologies Used
- Python
- File handling
- Conditional statements

## How to Run
1. Install Python.
2. Create a sample text file named `sample.log`.
3. Add some example entries:
INFO: Application started
ERROR: Sample error message
WARNING: Sample warning message
INFO: Application stopped
4. Run:
python log_file_analyzer.py
5. Enter `sample.log` when prompted.

## Learning Outcomes
- Reading files in Python
- String operations
- Loops and conditions
- Understanding basic log analysis
